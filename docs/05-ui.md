# حسبة (Hesba) — UI/UX Specification (Visual & Behavioral Reference)

> Source: formerly `docs/05-ui.md`. Complete design system, screen states, colloquial copy, and accessibility rules.

> **The primary source is the demo:** `docs/demo/hesba-demo.html` (opens in the browser) and its source in `docs/demo/src/` (`style.css` + `*.jsx` files).
> **Rule:** the Agent **ports** the demo into real components. It must not invent a design or change colors/spacing/motion. This file explains the rules, and the demo is the judge.
> The demo uses React + localStorage only for experimentation. The **real logic** (stock/Sync) comes from `02`, `09` and `10`, not from the demo.

**Theme:** `data-theme="light|dark"` on `<html>`, or automatic via `prefers-color-scheme` (the value `auto` = no attribute). Stored in a local setting. `color-scheme` is set for each theme. **No hard-coded colors (hex) inside components**, only `var(--…)`.

### Font and text
- **Tajawal** (local woff2 from `public/fonts/tajawal/`, not from Google). `font-size: 16px; line-height: 1.5` as the base. Weights 400/500/700/800.
- No text smaller than 12px. Interactive text ≥ 14px.
- Direction `dir="rtl"` on `<html>`. Use logical properties (`inset-inline-start`, `margin-inline`, `padding-inline`) instead of left/right.

### Spacing and layout
- `content`: `padding: 14px`, `max-width: 1180px`, and inside it a bottom spacing for the mobile navigation: `calc(var(--nav) + 40px + env(safe-area-inset-bottom))`.
- Nothing sticks to the edge; a side gutter of 14–16px on mobile.
- Cards: `border-radius: var(--r)`, `box-shadow: var(--sh)`, `--line` borders.

## 2. Responsive
- **Mobile-first.** Mandatory testing at **320 / 360 / 390 / 430px** then 768 and 1280.
- The main breakpoint is **899px**: below it, the bottom navigation (4 items + "More"); above it, a side/top bar.
- **No horizontal scroll** at any width. (Check: element bounds inside the viewport, in a non-mobile-emulated context because the check is unreliable under emulation.)
- Bottom navigation: `الرئيسية · المنتجات · البيع · المخزون · المزيد` (Home · Products · Sell · Stock · More) (More: expenses, people, alerts, assistant, settings). A red counter on alerts.
- `env(safe-area-inset-*)` is respected (iPhone).
- At ≤ 380px: groups turn into a single column (`.stack-s`), the shop name in the header gets a `max-width`, and at ≤ 340px the logo in the header disappears.

## 3. Motion
- **Smooth and short.** Every open/close has motion: Modal/Sheet, the menu, Popover, Toast, page switching, list entry with a staggered delay.
- **Exit matters as much as entry:** the Modal, menu, Popover and Toast each run an exit animation (`.out`) before being removed (the demo does this with `useGhost`: it clones the element and plays the exit after the unmount).
- Curve `var(--ease)`. Common motions last 160–260ms (read the values from `style.css`).
- **`prefers-reduced-motion`:** disable the motion (the demo has the media query).
- The sliding control (`Seg`): the thumb moves via CSS vars (`--n` number of options, `--i` index).

## 5. Screens (behavior + states)

> **Single-Route Shell Architecture (ADR-0013):** The application is served via a single Next.js catch-all route (`/app/[[...slug]]`). The 8 core sections below are internal client views (`src/client/app-shell/views/*View.tsx`) managed by the shell's internal router, not separate App Router server routes. `HomeView` is loaded eagerly; the other 7 views are loaded lazily on demand within a `<Suspense>` boundary displaying localized loading text from `ar.json`, and are precached by Serwist for full offline availability.

### 5.0 Signup and login
- **Two steps:** (1) **About you:** name, mobile (`^01[0125]\d{8}$`), email (optional, format check), password (≥ 6). (2) **Your shop:** shop name, type (`سوبر ماركت · بقالة · ميني ماركت · جملة / نص جملة · أخرى` (supermarket · grocery · mini market · wholesale / semi-wholesale · other)), governorate (governorates list), area (optional), shop opening date, number of staff (Stepper), and the option "start with sample data" (`ابدأ ببيانات تجريبية`).
- After step 1: **OTP** (a simple verification screen). Attempt limits and resend from `12`.
- Login: mobile + password. Error messages in colloquial Arabic.
- In production: sample data = **real data ready to delete**, not fake data mixed in; it is tagged `demo=true` and deleted with one button. (A product decision in `15`.)

### 5.1 Home
- **PeriodBar** on top. Cards: sales, profit, expenses, (net). A chart (hourly if a single day). Top products. Brief alerts.
- **Profit = sales − cost of goods sold − expenses** (cost of goods sold from `sale_lines.cost_minor`, and voided sales are excluded).
- Empty: "لسه مفيش مبيعات في الفترة دي" (No sales yet in this period).

### 5.2 Products
- Search + filter (**الكل · قرب يخلص (n) · خلصان (n)** (All · Running low (n) · Out of stock (n))) + list. Each product: name, balance, price. Opening = edit (`ProductFormModal`).
- **Add product:** search the catalog first (match "is this the same as X?" — `ده نفس X؟`), otherwise a custom product. Type: piece / weight. Carton (number of pieces) optional. Price (piece or kilo), carton price.
- **"Suggestions" tab** from other shops (06): a card [Add] [Not needed] [Report] (`إضافة` / `مش محتاج` / `بلّغ`).

### 5.3 Stock
- **Add goods:** product (Combobox + create a new product from inside), quantity (in a suitable unit), **total cost**, expiry date (optional), supplier (optional), **paid / on credit**.
- **Additions log** (tab). On a large screen both columns are visible together.
- **Waste:** record the quantity of an expired/damaged batch.
- Balance = sum of the batches' `remaining_base`.

### 5.4 Sell (the most important)
- Top of the screen: **SearchBox** + today's total bar (pill) + color key.
- Product **tiles**: one tap = sell one piece immediately + Toast "اتباع…" (Sold…) with **undo** (`تراجع`).
- **Carton:** a tile with the carton price (deducts `pack_qty` pieces).
- **Weight:** a tap opens `WeightPopover`: Seg (kg/gram) + number field + quick shortcuts (**gram: 100·250·500·1000** — **kg: 0.25·0.5·1·2**) + a sell button with the computed price.
- **Out of stock:** the tile is clearly disabled ("خلصان" (Out of stock)), or sell with a warning according to the decision in `15` (default: **allow and flag negative** because the real-world sale already happened).
- **Undo:** performs `sale.void` on the last operation.
- Performance: the list is Virtualized if there are many products. Tiles must respond in under a moment (writing is local).

### 5.5 Expenses
- **Categories (Chips):** electricity · internet · rent · salaries · transport · maintenance · other (`كهرباء · نت · إيجار · مرتبات · نقل · صيانة · أخرى`). Amount + a "Record" button (`سجّل`). A link "ملاحظة أو يوم تاني؟" (A note or another day?) opens a note and a date.
- **PeriodBar** + period total + summary by category + list (delete with undo).
- Buying goods is **not** here (it is recorded in stock).

### 5.6 People
- **Three sections:** **ليك** (Owed to you — someone who owes you money) · **عليك** (You owe — you are the debtor) · **الموردين** (Suppliers).
- Each one: name, mobile (optional), amount, note. Suppliers: + their products. Total for each section.
- A call/WhatsApp button for the number (`tel:`/`wa.me` link without an API). No detailed account statement in V1.

### 5.7 Alerts
- Three types: **Out of stock** · **Running low** · **Near expiry** (a batch whose expiry is within **7 days** or less) + catalog suggestions.
- A counter on the navigation icon. Each alert leads to the action (add goods / sell at a special price is not in V1).
- Default thresholds in `09` section 8.

### 5.8 Assistant (AI)
- A simple chat. The **remaining-messages counter (5 per day)** is visible. When it runs out: a clear lock state ("خلص حدك النهارده، ارجع بكرة" (You've used your limit for today, come back tomorrow)).
- Suggested questions (chips). **Answers come from the shop's data only**, with no invented market numbers. If unable: "مش عندي بيانات كفاية" (I don't have enough data).
- Online only. Offline: "المساعد محتاج نت" (The assistant needs internet).

### 5.9 Profile and settings
- `ProfileModal`: shop and account data, sharing settings (06): "متشاركش منتجاتي المخصصة" (Don't share my custom products), "استقبال اقتراحات" (Receive suggestions). Theme. Stock export (CSV). Logout. Delete account/export data (from `12`).

## 6. Offline and sync in the UI
- **SyncBar** states: `متزامن ✓` (Synced) · `بيزامن…` (Syncing…) · `X عمليات مستنية (أوفلاين)` (X operations waiting (offline)) · `في عمليات محتاجة مراجعة` (Some operations need review) · `السيرفر بيتحدّث، شغلك محفوظ` (The server is updating, your work is saved) (503) · `سجّل دخولك` (Log in) (401, without stopping selling).
- **Offline:** a calm, non-scary bar. Everything essential works.
- **"Needs review":** a list of operations rejected, each with a reason in colloquial Arabic + a retry/ignore button.
- **App update:** a simple screen that preserves the queue.
- **PWA install:** a gentle install prompt after the first successful use, not on the first screen.

## 7. Mandatory states for every screen
`Loading` (light Skeleton) · `Empty` (message + action) · `Error` (message + retry) · `Offline` · `Pending sync` · `Read-only` (expired subscription) · `Demo data`.

## 8. Copy (colloquial)
- Short, direct, without jargon. Examples: "اتسجل" (Recorded), "مفيش منتجات" (No products), "تضيفه عندك؟" (Add it to yours?), "اكتب المبلغ" (Enter the amount), "النت واقع، شغلك محفوظ" (Internet is down, your work is saved).
- All in `ar.json` with fixed keys. No text in components. Numbers and currency (`ج.م` (EGP)) via a single formatting function.
- Suggestion buttons: **"إضافة"** (Add) and **"مش محتاج"** (Not needed).

## 9. Performance (measured targets)
- The core interaction (sell) is local and instant: under a perceptible moment on a mid-range Android.
- A small initial bundle with a size budget in CI (the number is set after the first Build). Heavy pages and libraries are lazy.
- Lighthouse on a weak device (Throttling) before the Alpha.
- No layout shift on font load (preload the woff2 + `font-display`).
- Virtualized lists for any list > hundreds of rows.

## 10. Accessibility (A11y)
- Touch targets ≥ 44×44px. Acceptable color contrast in both themes.
- Every interactive element works by keyboard, a visible focus ring, `aria-label` for icons.
- Modal: focus trap + focus restoration + Esc. Toast: `role="status"`.
- No reliance on color alone (icon/text with out-of-stock and warning).
